# mkdocs-carve

MkDocs plugin for `.crv` documentation pages, using carve-lang 0.1.11 or later. Carve and Markdown pages can share a site. Read the [Carve documentation](https://markup-carve.github.io/carve/) for the language syntax.

## Install

```sh
pip install mkdocs-carve
```

## Usage

```yaml
plugins: [carve]
```
